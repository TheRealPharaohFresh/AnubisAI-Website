Frequently asked questions

What we can confirm.

Can I install or try the application?

Not from this website. An unsigned, unnotarized Intel macOS development build has been tested locally, but there is no approved public installer. See the downloads page.

What can Anubis AI do today?

The development build includes a local task/approval command center, Anubis coordination, and Thoth for bounded software-development work in an approved project workspace. See product details.

Does it work with cloud AI providers?

Gemini and Groq adapters are implemented but have not been tested with live credentials. Cloud requests are disabled by default. Ollama is supported locally, and a local generation was tested. Prompts sent to an enabled cloud provider are governed by that provider’s terms.

Is it secure for remote or team use?

No. The API is designed for loopback-only local use and authentication is not implemented. Do not expose it to a network. Full security review and additional hardening remain outstanding.

Can I subscribe or cancel?

No subscription checkout or billing management is active. The beta and full-product prices are planning targets only.

Which operating systems are supported?

Only a local Intel macOS development package is reported tested. Apple Silicon, Windows, and Linux have not been verified as supported release targets.

Will there be other editions?

Zeus AI, Odin AI, and Anu AI are proposed future editions, not available products. No builds or installers exist for them.
